# Euskara Bidea

App interactiva para aprender euskera (nivel A1): lecciones, vocabulario, conjugación y construcción de frases.

- Aplicación: `index.html` (un único archivo, sin dependencias; funciona en Safari, Chrome y móvil).
- Dirección: https://pekemtir.github.io/euskara-bidea/
- Historial de cambios: [CHANGELOG.md](CHANGELOG.md)

El progreso de estudio se guarda en el navegador de cada dispositivo, no en este repositorio.
